# Share links

A share link lets someone without an account see a read-only copy of a repository. For example, a client who wants to review a design, or a fab house that needs your files.

## Create a link

Repository admins can open **Settings → Share links**. You can set:

- **Revision:** a branch, tag or commit. A branch link follows the branch. A commit link never changes.
- **Folder or file:** share only part of the repository.
- **Expires:** 1 to 90 days, or never.
- **Allow downloads:** turn it off to allow viewing only.
- **Watermark:** text shown over the page, like "Confidential".

The link is shown once. Jumper only keeps a hash of it, so if you lose it, make a new one.

## What people can see

The file tree, text files, images, PDFs, and the renders and reports from checks. HTML and scripts are never shown inline.

## Revoke a link

Revoke it on the same page and it stops working right away. Links also stop if the person who made them is disabled or the repository is deleted.

## Keep in mind

- Anyone with the link can use it. Treat it like a password.
- View-only does not stop someone from taking screenshots. Don't share what you can't afford to leak.
- Each view is counted. The list shows views and the last visit.
